## 📖 ¿Qué es Network Map Lite?

**Network Map Lite** es una aplicación web pensada para **registrar contactos profesionales** y **descubrir relaciones, intereses y oportunidades de colaboración** a través de un **grafo interactivo**.

Es una herramienta ligera, sin backend, que vive completamente en tu navegador: tus datos se guardan de forma local y tu red se mantiene disponible entre sesiones.

## 🎯 ¿Para qué sirve?

- 📇 Mantener tu red profesional ordenada en un solo lugar.
- 🔗 Relacionar contactos y descubrir posibles oportunidades.
- 🕸️ Ver tu red como un grafo interactivo, no como una lista plana.
- 💾 Conservar la información sin necesidad de cuentas ni servidores.

## 💾 Tus datos, siempre contigo

La red de contactos puede crecer con el tiempo, por eso **Network Map Lite** guarda todo **localmente en tu navegador**. Así, tu información se mantiene entre sesiones sin necesidad de un backend, cuentas ni servicios externos.

Es simple, privado y tuyo.

---

## ✨ Lo más llamativo: el grafo interactivo

El corazón de la aplicación es un **grafo visual** donde:

- 🟢 Cada **nodo** es un contacto.
- 🔗 Las **conexiones** aparecen dinámicamente al elegir intereses comunes.
- 🖱️ Puedes explorar tu red de forma visual, intuitiva y fluida.

---

## ⚙️ ¿Qué puedes hacer?

### 📇 Registrar contactos
Añade personas a tu red profesional con su nombre, empresa e interés.

### ✏️ Editar contactos
Actualiza la información de cualquier contacto para mantenerla al día.

### 🗑️ Eliminar contactos
Quita de tu red a quienes ya no aportan valor.

### 🔗 Crear conexiones
Relaciona dos contactos e indica el motivo, para visualizar oportunidades de colaboración.

### 🔍 Filtrar la red
Encuentra contactos por interés, texto de búsqueda o empresa, y descubre conexiones relevantes.
